# Попутка ИИ — Студенческий райдшеринг

![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)
![Flask](https://img.shields.io/badge/flask-3.0-green.svg)

Умный сервис райдшеринга для студентов УрФУ с AI-матчингом, интерактивной картой на 2GIS, QoL-предпочтениями для пассажиров и QWL-ограничениями для водителей.

## Возможности

- **Интерактивная карта 2GIS** — ставьте метки «Откуда» и «Куда» кликом по карте
- **Свободный ввод адресов** — вводите любой текст, геокодирование происходит на сервере
- **AI-матчинг** — подбор попутчиков по маршруту, времени, предпочтениям и рейтингу
- **Отмена запросов** — пассажир может отменить открытый запрос
- **Регистрация с любым email** — флаг `ALLOW_ANY_EMAIL` отключает проверку домена
- **QoL предпочтения** — музыка, разговорчивость, кондиционер, курение
- **QWL ограничения** — контроль часов вождения, режим «По пути домой»
- **Бонусы за непиковые часы** — 10-15% за поездки в спокойное время
- **Кнопка SOS** — уведомление экстренных контактов
- **Система рейтингов** — оценка по 5 критериям

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Backend | Python 3.10+, Flask |
| База данных | SQLite + SQLAlchemy |

## 🚀 Инструкция по запуску

### 1. Откройте командную строку

### 2. Перейдите в папку проекта
```cmd
cd "C:\Users\stank\OneDrive\Рабочий стол\UrFU hahaton\poputka-ai"
```

### 3. Создайте виртуальное окружение
```cmd
python -m venv venv
```

### 4. Активируйте виртуальное окружение
```cmd
venv\Scripts\activate
```

### 5. Установите зависимости
```cmd
pip install -r requirements.txt
```

### 6. Наполните базу демо-данными (только первый раз)
```cmd
venv\Scripts\python.exe data/seed.py
```

### 7. Запустите приложение
```cmd
venv\Scripts\python.exe app.py
```

### 8. Откройте браузер
Перейдите по адресу: **http://127.0.0.1:5000**

### Остановить сервер
Нажмите **Ctrl+C** в командной строке.

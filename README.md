# Попутка ИИ — Студенческий райдшеринг

![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)
![Flask](https://img.shields.io/badge/flask-3.0-green.svg)
![License](https://img.shields.io/badge/license-MIT-lightgrey.svg)

Умный сервис райдшеринга для студентов УрФУ с AI-матчингом, QoL-предпочтениями для пассажиров и QWL-ограничениями для водителей.

## Возможности

### Для пассажиров (QoL — Quality of Life)
- **Текстовый ввод запроса** — опишите поездку своими словами, AI распознает параметры
- **Настройка предпочтений** — музыка, разговорчивость, кондиционер, курение
- **Гибкий поиск** — укажите допустимое отклонение по времени
- **Умный матчинг** — AI подбирает лучшие варианты с объяснением совместимости
- **Система оценок** — оценивайте водителей по 5 критериям

### Для водителей (QWL — Quality of Work Life)
- **Контроль нагрузки** — ограничение часов вождения в день
- **Режим "По пути домой"** — без заездов во дворы, строго по маршруту
- **Бонусы за непиковые часы** — дополнительные 10-15% за поездки в спокойное время
- **Динамическое ценообразование** — цена зависит от расстояния, пробок и спроса
- **Регулярные маршруты** — создайте один раз, используйте каждый день

### Общие функции
- **Регистрация только для студентов УрФУ** (@stud.urfu.ru)
- **Верификация email** с кодом подтверждения
- **Кнопка SOS** с уведомлением экстренных контактов
- **Внутренние уведомления** о ключевых событиях
- **Система рейтингов** с расширенными критериями

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd poputka-ai
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

```bash
cp .env.example .env
```

Откройте `.env` и при необходимости настройте:
- `SECRET_KEY` — секретный ключ сессий (уже установлен для разработки)
- `TWOGIS_API_KEY` — ключ API 2GIS (опционально, по умолчанию мок)
- `RUSENDER_API_KEY` — ключ RuSender для email (опционально, по умолчанию мок)
- `OPENAI_API_KEY` — ключ OpenAI для парсинга текста (опционально, по умолчанию regex)

### 5. Наполнение демо-данными

```bash
python data/seed.py
```

Это создаст 5 пользователей, маршруты, поездки и оценки для демонстрации.

### 6. Запуск приложения

```bash
python app.py
```

Откройте браузер и перейдите по адресу: **http://localhost:5000**

## Как работает матчинг

Формула расчёта совместимости:

```
score = 0.35 * time_score + 0.2 * distance_score + 0.3 * compatibility_score + 0.15 * rating_score
```

- **time_score** — насколько время поездки совпадает с желаемым (0-1)
- **distance_score** — расстояние от точки пассажира до маршрута водителя (0-1)
- **compatibility_score** — совпадение предпочтений: музыка, разговорчивость, кондиционер, курение (0-1)
- **rating_score** — средний рейтинг водителя по всем критериям (0-1)

Для режима "По пути домой" (zero_stress_mode) максимальное расстояние сокращается до 500 м.

## Динамическое ценообразование

```
base_price = 50 + (distance_km * 15)
total = base_price * traffic_multiplier * demand_multiplier
price_per_seat = max(total / seats_total, 30)
```

Минимальная цена — 30 рублей. При действующем бонусе цена может быть снижена на 10%.

## API интеграции

### 2GIS (геокодинг и пробки)
По умолчанию используется мок с координатами основных точек Екатеринбурга. Для подключения реального API:
1. Получите ключ на https://docs.2gis.com/
2. Установите `MOCK_2GIS=false` и `TWOGIS_API_KEY=ваш_ключ` в `.env`

### RuSender (email)
По умолчанию код подтверждения выводится на экран. Для подключения:
1. Получите ключ RuSender
2. Установите `MOCK_EMAIL=false` и `RUSENDER_API_KEY=ваш_ключ` в `.env`

### OpenAI (парсинг текста)
По умолчанию используется regex. Для подключения GPT:
1. Получите ключ на https://platform.openai.com/
2. Установите `OPENAI_API_KEY=ваш_ключ` в `.env`

## Сценарии использования

### Сценарий 1: Пассажир ищет поездку
1. Зарегистрируйтесь под `petrova@stud.urfu.ru`
2. Перейдите в "Найти поездку"
3. Введите: "Еду в 8:40 от Уралмаша до УрФУ"
4. Нажмите "Распознать" и подтвердите параметры
5. Получите результаты матчинга с % совместимости
6. Примите подходящее предложение

### Сценарий 2: Водитель создаёт маршрут
1. Зарегистрируйтесь под `ivanov@stud.urfu.ru`
2. Перейдите в "Создать маршрут"
3. Заполните: Откуда=Уралмаш, Куда=УрФУ, время=08:30, дни=Пн-Пт
4. При желании включите "Режим 'По пути домой'"
5. Укажите дату для создания конкретной поездки
6. Система рассчитает цену и покажет подсказку о бонусе

### Сценарий 3: SOS
1. Войдите как пассажир в активной поездке
2. Нажмите красную кнопку SOS
3. Подтвердите действие
4. Экстренные контакты получат уведомление
